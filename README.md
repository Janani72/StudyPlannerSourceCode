# Smart Study Planner

Smart Study Planner is a Flutter-based student productivity application
designed to help students organize their study schedules, assignments,
exams and daily tasks efficiently.

## Features

- Study Schedule
- To-Do List and Reminders
- Assignment Tracker
- Exam Countdown
- Pomodoro Timer
- Daily Progress Tracking
- Achievement Badges
- Firebase Authentication
- Cloud Firestore
- Dark Mode

## Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Provider
